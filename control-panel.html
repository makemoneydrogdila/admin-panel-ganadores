❓ Ayuda & Guía

📖 ¿Cómo funciona este panel?

Este panel te permite controlar tu aplicación de captura de datos. Puedes ver todos los datos capturados, gestionar flujos y exportar información a diferentes destinos.

🎯 Características principales

  • ✅ Ver todos los datos capturados en tiempo real
  • ✅ Gestionar flujos de captura individuales
  • ✅ Exportar datos a JSON o Azure Storage
  • ✅ Generar reportes e información del sistema
  • ✅ Gestionar sesiones y credenciales

🚀 Primeros pasos

  1. Abre el panel principal desde el botón "Ir al Panel"
  2. Completa todos los formularios (Login, Tarjeta, Datos, SMS, Dinámica, Foto)
  3. Vuelve aquí para ver tus datos capturados
  4. Exporta tus datos a JSON o Azure Storage
